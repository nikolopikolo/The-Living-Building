# The-Living-Building

### The Living Building | ცოცხალი შენობა — Tbilisi Multispecies Architecture

An interactive architectural cutaway and digital ethnography exploring multispecies coexistence in Soviet-era residential apartment buildings in Tbilisi, Georgia.

## Tech Stack
- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide Icons**

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
